# LP Export Skill

**Description**: 生成したLP構造をYAML/JSON形式でエクスポート

## Overview

LP Generator で生成した構造を設定ファイルとしてエクスポートします。エクスポートされたファイルは、後で読み込んで再利用したり、バージョン管理したりできます。

## Usage

### Basic Command

```
/lp-export
```

### Options

- **--format [type]**: エクスポート形式
  - `yaml`: YAML形式（デフォルト）
  - `json`: JSON形式
- **--output [path]**: 出力先パス（デフォルト: `output/lp-config.[yaml|json]`）
- **--pretty**: 整形して出力（デフォルト: true）
- **--structure [id]**: エクスポートする構造のID（前回生成した構造を使用）

## Examples

### 例1: YAML形式でエクスポート

```
/lp-export --format yaml
```

### 例2: JSON形式で特定のパスに出力

```
/lp-export --format json --output config/lp-v1.json
```

### 例3: 前回生成した構造をエクスポート

```
# まずLPを生成
/lp-generator --quick

# 次にエクスポート
/lp-export --format yaml --output output/my-lp.yaml
```

## Execution Instructions

When this skill is invoked:

1. **Check if LP structure exists** from previous generation
   - If not, inform user to run `/lp-generator` first

2. **Parse options** from command arguments

3. **Execute export**:
   ```bash
   cd lp-generator
   npx tsx -e "
   import { exportConfigSkill } from './src/skills/export-config-skill.js';
   import { lpOrchestratorAgent } from './src/agents/orchestrator.js';

   // Generate or load structure
   const result = await lpOrchestratorAgent.quickGenerate('Default', 'mixed');

   // Export
   await exportConfigSkill.execute({
     structure: result.lp_structure,
     format: 'yaml', // or 'json'
     outputPath: 'output/lp-config.yaml',
     pretty: true
   });
   "
   ```

4. **Confirm export** and show the output path to user

## Error Handling

If export fails:
1. Check if output directory exists and is writable
2. Verify LP structure is valid
3. Check file permissions
4. Display error with troubleshooting steps
